# Iris Flower Classifier

This project is a machine learning classification model to predict the species of Iris flowers based on their sepal and petal dimensions (length and width). The model is trained using the popular Iris dataset and utilizes a machine learning algorithm to classify the species into three classes: **Setosa**, **Versicolor**, and **Virginica**.

## Introduction

The Iris dataset is one of the most famous datasets used for classification tasks in machine learning. This project aims to explore the data and create a model that can accurately predict the species of Iris flowers based on their features.

## Model
This project uses the K-Nearest Neighbors (KNN) classifier from scikit-learn to predict the species of the Iris flowers. The model is evaluated using accuracy.
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
## Conclusion
The Iris Flower Classifier is a simple yet effective demonstration of classification using machine learning algorithms. It can be extended to other datasets and classification algorithms for further learning and exploration.
